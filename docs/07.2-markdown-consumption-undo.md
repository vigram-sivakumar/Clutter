## Purpose of This Document

This document defines **exactly what happens after** a markdown trigger fires.

It answers permanently:

- What text is consumed
- What text is preserved
- How caret placement is handled
- How undo/redo behaves
- What intermediate states are forbidden
- What Cursor AI must never implement

**If behavior deviates from File 07.2, it is incorrect by definition.**

---

## 0. Core Principle (Non-Negotiable)

### Markdown Conversion Is Atomic

Markdown conversion is a **single, indivisible operation**.

There must **never** exist a user-observable state where:

- The prefix exists without conversion
- The space exists as text
- The variant is changed but text is not
- Undo partially reverts markdown

**Atomic means:**

> Either the markdown conversion happens completely, or it does not happen at all.

---

## 1. Conversion Boundary (Critical)

Markdown conversion occurs **before** any text mutation.

### Order of Operations (MANDATORY)

```
keydown(" ")
→ markdown detection (File 07.1)
→ if match:
     preventDefault()
     perform conversion
→ else:
     browser handles space normally
```

**Forbidden:**

- ❌ Insert space, then remove it
- ❌ Insert prefix into state, then clean it
- ❌ Use `input` or `useEffect` to "fix" text
- ❌ Retroactive cleanup

---

## 2. Text Consumption Rules (LOCKED)

When a markdown shortcut triggers:

### 2.1 Consumed Text

The following are **fully removed** and **never enter history**:

- The prefix characters  
  (`[]`, `-`, `#`, etc.)
- The triggering space (`␣`)

### 2.2 Preserved Text

- Any text typed after the space remains
- Any text already present after prefix remains

### 2.3 Examples (Authoritative)

| User Input    | Final `node.text` |
| ------------- | ----------------- |
| `[]␣`         | `""`              |
| `[]␣buy milk` | `"buy milk"`      |
| `-␣hello`     | `"hello"`         |
| `#␣Title`     | `"Title"`         |

**The space is never inserted.**  
**The prefix is never stored.**

---

## 3. Caret Placement Semantics

### 3.1 Placement Rule

After markdown conversion:

- Caret offset = `0`
- Selection = `null`
- Caret placement is explicit and intentional

This is one of the **allowed caret interventions** under File 06.1.

### 3.2 Ownership Model

- Browser renders caret
- Editor may place caret **once**, immediately after conversion
- Editor must **not** "track" caret after that

---

## 4. Undo / Redo Semantics (CRITICAL)

### 4.1 Undo Is Single-Step

Markdown conversion must create **exactly one undo entry**.

**Undo restores:**

- Previous node variant
- Original text (including prefix, without space)
- Original caret position (before space key)

**Redo reapplies:**

- Variant conversion
- Text consumption
- Caret placement at offset 0

### 4.2 Forbidden Undo States

The following must **never** appear in undo history:

- Prefix without conversion
- Prefix + space
- Converted variant with prefix text
- Any intermediate cleanup state

---

## 5. State Mutation Rules

### 5.1 What Markdown Is Allowed to Mutate

Markdown conversion may mutate **only**:

- `node.props.variant`
- `node.text`
- `activeNodeId`
- `offset`
- Undo history (single snapshot)

### 5.2 What Markdown Must NOT Touch

- ❌ Selection state (except clearing)
- ❌ Other nodes
- ❌ DOM text post-facto
- ❌ Grammar session state (grammar already resolved)
- ❌ Input observers
- ❌ Effects or async cleanup

---

## 6. Implementation Constraints (MANDATORY)

### 6.1 Where Conversion Happens

- Only in `keydown`
- Only when `event.key === " "`
- Only after File 07.1 trigger conditions pass

### 6.2 Data Sources (STRICT)

Markdown detection and execution must use:

- DOM selection (via Range API)
- DOM text content of active `.node__content`

Markdown must **not** rely on:

- ❌ React state timing
- ❌ `editorState.offset`
- ❌ `selectionchange` having fired
- ❌ Input events

---

## 7. Explicit Forbidden Patterns (DO NOT IMPLEMENT)

Cursor AI must **never**:

- ❌ Insert then delete text
- ❌ Use regex cleanup after typing
- ❌ Modify DOM in `useEffect`
- ❌ Rely on async state settling
- ❌ Store prefix in state temporarily
- ❌ Treat space as text
- ❌ Split markdown into multiple commits

**If any of these appear, the implementation is invalid.**

---

## 8. Validation Checklist (MUST PASS)

### Task Variant (`[]␣`)

- ✅ Conversion happens immediately on space
- ✅ Prefix is not visible
- ✅ Space is not visible
- ✅ Text preserved
- ✅ Caret at offset 0
- ✅ One undo restores exact previous state

### Bullet (`-␣`) / Heading (`#␣`)

- Same guarantees as above
- No visual flicker
- No delayed conversion
