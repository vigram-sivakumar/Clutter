## Why Deprecated

The `bias` field described in this document **no longer exists**.

The segmented architecture migration (Feb 2026) replaced the bias mechanism with:
- `cursor.segmentIndex` - Which segment the cursor is in
- `cursor.offset` - Position within that segment
