# Clutter Structured desktop

Single product composition: Tauri host + shared React UI + headless Core/runtime.
This replaces both the legacy application entry and disposable two-box Foundation UI.
No old CM6/Markdown/compact Markdown/vault/persistence pipeline remains in the product.

Run `npm run desktop` from the repository root; see
[development](../../docs/development.md) and [architecture](../../docs/architecture.md).
Synthetic development Spaces only. Native Mac verification is pending for this entry.
