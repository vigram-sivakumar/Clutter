Told you this one took some work. Tables in Markdown are usually a pain, so I tried hard to make them feel easy
## Making a table
- Write a header row with `|` between the columns, like `| Name | Role |`
- On the next line, add `| --- | --- |` and you’ve got a table
- Or just copy a few cells from a spreadsheet and paste them in. Clutter builds the table for you
| Name | Role            | Favourite shortcut |
| ---- | --------------- | ------------------ |
| Me   | Wrote this note | `⌘ N`              |
| You  | Reading it      | Still deciding     |
## Moving around
- Press `Tab` to jump to the next cell and `⇧ Tab` to go back
- Press `Enter` in a cell to add a new row below it
- Use the arrow keys to move in and out of the table
## The handles
Hover over a row or column and a small handle shows up. Click it for a menu that lets you
- Insert rows and columns above, below, left or right
- Move, duplicate or delete them
- Align a column left, center or right
- Format table, to tidy up the Markdown underneath
  **Tip:** drag a handle to reorder rows and columns, or drag the edge of a column to resize it #Tip
