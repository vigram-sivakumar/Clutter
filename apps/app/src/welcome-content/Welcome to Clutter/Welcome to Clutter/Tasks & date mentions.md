Half my notes end with a list of things to do, so tasks live right inside them
Any checkbox you write, in any note, shows up in your Tasks view too. No copying things around
## Making a task
- Type `- [ ]` and a space to start a task
- Or the lazy way: type `[]` and a space at the start of a line
- Press `⌘ ⇧ T` from anywhere to create one
Click the checkbox when you’re done. Clutter quietly notes the day you finished it, no extra clutter on the page
- [ ] Like this one. Go on, tick it off 
## Mentioning a date
Type `@` and start writing a date the way you’d say it
- `@today`, `@tomorrow` or `@yesterday`
- `@fri`, `@next friday` or `@in 3 weeks`
- `@24th`, `@12 mar` or `@march`
- Add a time if you like, `@tomorrow 4pm`
Pick the suggestion and it becomes a date chip. Click it to open that day’s daily note
**Tip:** put a date on a task and it becomes the due date. Your Tasks view sorts it into Today, Upcoming or Overdue for you #Tip

>Behind the scenes a date is saved as plain text, like `@2026-10-30`, so your notes still read well in any other Markdown app
