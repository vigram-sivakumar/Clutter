Let’s start small, with the styles that live inside a sentence
Wrap a word in a few symbols and Clutter styles it as you type. The symbols hide once you move on and come back when you click into the word, so editing is never a guessing game
## The everyday ones
- Use `**Text**` to bold any text or use `__` 
- For italic use double `*` or `_` 
- Strikethrough can be created using thr `~` 
- & to highlight use the double `==` 
- Wrap texts with `backticks` for Inline code
**Tip:** select some text first and the shortcut wraps it for you #Tip

>One exception: whatever sits inside `**backticks**` stays exactly as you typed it. Handy when you want the symbols to show
