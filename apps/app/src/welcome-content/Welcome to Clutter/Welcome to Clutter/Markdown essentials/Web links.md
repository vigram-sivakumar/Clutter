Wiki links take care of your own notes. For everything else out there on the internet, there are web links
## Adding a link
- Type `[text](address)`, like `[Unsplash](https://unsplash.com)`, and only the text shows up
- Or skip the brackets and type the address on its own. https://unsplash.com, www.unsplash.com, even unsplash.com becomes a link
- Click a link to open it in your browser
## Pasting a link
Paste an address and Clutter asks how you’d like it
- **Markdown link** turns it into a proper link
- **URL** keeps it as the address itself
**Tip:** select some text first, then paste the address. Pick Markdown link and your text becomes the link #Tip

>Want an address to stay plain text? Wrap it in backticks, like `unsplash.com`
