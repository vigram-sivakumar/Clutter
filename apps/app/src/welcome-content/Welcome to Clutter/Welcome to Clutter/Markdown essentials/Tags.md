Folders are great until a note belongs in two places. That’s where tags come in
Drop a tag anywhere in a note, like #Ideas right here, and it joins every other note with the same tag, no matter which folder it lives in
## Adding a tag
- Type `#` followed by a word, like `#ideas` or `#reading-list`
- Start typing after `#` and Clutter suggests the tags you already have
- Press `⌘ ⌃ T` to create a new tag from anywhere
- Or keep the page clean and add tags to the note’s properties instead. Use Add properties in the note’s header, pick Tags and type away. Spaces turn into `-` for you
Tags can have letters, numbers, `-` and `_`, but no spaces. Use `#weekly-review` instead of `#weekly review`
## Finding your way back
- Click any tag to see every note that uses it
- Press `⌘ 4` to open the Tags view and browse them all
- Renaming a tag there renames it in every note too
**Tip:** got a pile of tags nobody uses anymore? Tidy up in the Tags view clears them out, and can even make all your tags look the same, like `lowercase` or `Title Case` #Tip

>A `#` on its own, a number like `#2026`, or one inside `inline code` stays plain text. So your headings and issue numbers are safe
