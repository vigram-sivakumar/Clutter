Not everyone needs this one, but if you keep snippets around, you’ll love it
## Making a code block
- Type three backticks ` ``` ` on a new line. Clutter adds the closing ones for you
- Add the language right after them, like ` ```js `, and the code gets colour
```js
const note = "Hello from Clutter";
console.log(note);
```
## The menu
Each block has a copy button for grabbing the code in one click, and a menu that lets you
- **Change language**, search and pick from the list
- **Format code**, to tidy up messy code in one go
- **Download code**, to save it as a file with the right extension
- **Remove** the block
**Tip:** Format code works for JavaScript, TypeScript, JSON, CSS and HTML. The other languages still get their colours #Tip

>Need just a bit of code inside a sentence? That’s inline code, wrap it in single backticks or press `⌘ E`
